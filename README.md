📱 Mobile Phones E‑Shop Project

This repository contains a full-stack PHP e-commerce web application that I developed as part of a university project with two classmates. The site simulates a mobile phone online store, enabling users to browse and purchase products online.

🔍 Overview

Our team built this application to provide a realistic e-shop experience, including:

User authentication – registration, login, and session management

Product browsing – customers can view mobile phones and details

Shopping cart functionality – users can add products to the cart and manage orders

Order management – users can view their purchases and order history

Responsive UI using HTML/CSS, JavaScript, and Bootstrap

Database integration with MySQL for persisting users, products, and orders

🛠️ Tech Stack

PHP for server-side backend logic

MySQL for database management

HTML5 & CSS for structure and styling

JavaScript for client-side interactivity

Bootstrap for responsive design

🚀 Setup

Install a local PHP server (XAMPP)

Clone this repository into your server’s web folder

Create a MySQL database and import the provided SQL file

Update the database connection in config.php
